# Amazon SageMaker

### What is SageMaker

- SageMaker is a product that offers Machine Learning Services. We can think it as MachineLearning as a Service.
- SageMaker is a fully managed machine learning service provided by Amazon Web Services, AWS. SageMaker makes it easy to build, train, and deploy machine learning models at scale.
- It handles the heavy lifting of infrastructure, data prep, and scaling, so you can focus on building and refining your machine learning models
  - Build Models quickly
  - Train models at scale
  - Deploy models to production environments

### What is SageMaker Studio

- An IDE that lets you build, train and deploy models

### What is SageMaker Data Wrangler

- Simplifies the process of preparing data by providing charts and graphs
- SageMaker Data Wrangler, a tool that simplifies the process of preparing data for machine learning by providing charts and graphs for data exploration and transformation.

### What is SageMaker Feature Store

- Fully managed repository to store and retrieve machine learning features
- SageMaker Feature Store, a fully managed repository to store and retrieve machine learning features, enabling consistent feature usage across models.

### What is SageMaker Processing

- Framework to run preprocessing and post-processing workloads at scale
- SageMaker Processing, provides a framework to run pre-processing and post-processing workloads such as data cleaning and feature engineering at scale.

### What is SageMaker JumpStart

- Set of pre-built solutions and example notebooks to kickstart machine learning projects
- SageMaker Jumpstart offers a set of prebuilt solutions and example notebooks that can help you kickstart your machine learning projects quickly.
